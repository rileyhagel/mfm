Tag Reference

HTML tags consist of an opening tag and a closing tag. Example: <p>This is a paragraph.</p> The opening tag contains a letter or two, and the closing tag has a slash / before the letters.

Some tags have no closing tag, because they have no text content. For example: <img src="example.com/image.jpg" alt="Example Image">. The information inside the image opening tag example above consists of two attributes: src (source), and alt (alternate text to show if the image fails to load, or for people who use screen readers.)

In the table below, parts of the tag in square brackets ([]) are optional. Do not type the square brackets; they are not part of the code, and simply denote the sections that are optional. Replace sections in italics with your own text.

TagUsage
<p>content goes here</p> This is a paragraph tag. Use it for paragraphs.
<strong>content goes here</strong> Use to say something strongly.
<b>content goes here</b> Use to mark out key words.
<em>content goes here</em> Use to say something with emphasis.
<i>content goes here</i> Use to put something in italics when you are not speaking with emphasis.
<var>content goes here</var> y=32x+9

How To...?

Write the Email

Type HTML into the text area to write the email. Click "Update" to see the email in the box above. To type a new line, pressing enter will not work. For example: 

First Line
Second Line

Will result in:
First Line Second Line

To enter new lines, use the <br> HTML tag. For example: 

First Line <br>
Second Line

Or: 

First Line <br>Second Line

Will result in:
First Line
Second Line

HTML also ignores extra whitespace. For example: 

Super        Man

Will result in:
Super Man
(One space)

To learn how to write the HTML, close this dialog and click "Tag Reference".

Style your Email

To change the background, click "Paper" and select a paper style. Some papers are image textures that are tiled across the page, and others are standart CSS colors.

To change the typeface, click "Pens and Brushes" and select a typeface. All typefaces are basic browser font faces, as linking to remote font files or embedding them is not supported by most HTML email clients.
