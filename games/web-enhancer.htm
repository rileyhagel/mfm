How to play

The code

To play this game, copy the following scary-looking HTML to your clipboard:

<div style="background-color: white; color: black;"><div style="background-color: yellow; color: red; border-color: red; border-style: solid; border-radius: 10px; padding: 10px; margin: 10px;"><strong><center><big>WARNING!</big></center><br>THIS SCRIPT CAUSES ELEMENTS ON THE PAGE TO FLASH BRIGHT, HIGH CONTRAST COLORS AND DO WIERD STUFF WITH IMAGES. MFM TAKES NO RESPONSIBILITY FOR INJURY, INSANITY, OR ANY OTHER PHYSICAL OR MENTAL ISSUES CAUSED BY IT'S SOFTWARE.</strong></div><center><button onclick="fun()">FUN</button></center><script src="https://rileyhagel.github.io/mfm/games/web-enhancer.js"></script></div>

Then, visit the website of your choice. I did this in chrome, but what you are about to do is about the same in most modern browsers. Next, enter the developer mode in your browser. You can normally do this by pressing Ctrl+Shift+I. Navigate to the Elements tab. You should see the code for the webpage. Yuck. Find the following tag:

</body>

It should be at or near the bottom of the page. Right-click it. Select "Edit as HTML". Scroll to the bottom of all that mess. Put the cursor (the little line that blinks while you type) in right before </body>.

Now press Ctrl+V to paste the code in. Click outside the text-editing field (like, in the main browser viewport), and scroll to the bottom of the webpage. Find the button that says "FUN". Click it. Let the fun begin!
Note: Wait about 3 seconds for things to start working. You can always click refresh to go back to normal, but why would you want to do that? If it dosn't work, then they probably have a bunch of content-policy headers getting in the way and there's nothing you can do about it :( .
